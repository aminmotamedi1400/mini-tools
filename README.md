## ✨ **Why Mini-Tools?**

> *"Small tools, big impact."*

This collection is born from real-world needs—tools I built to solve specific problems I faced daily. Whether you're a student drowning in PDFs, a researcher managing citations, or just someone who wants to keep their digital life organized, there's something here for you.

- **🔍 Search Smarter** – Find anything, anywhere (PDFs, chat logs, markdown files)
- **📚 Manage Everything** – From thesis writing to grocery shopping
- **🚀 Boost Productivity** – Automate repetitive tasks and organize chaos
- **🛡️ Privacy First** – Everything runs **100% locally** – your data never leaves your machine

## 📦 **Installation**

```bash
# Clone the repository
git clone https://github.com/aminmotamedi1400/mini-tools.git
cd mini-tools

# Each tool has its own dependencies
cd "Tool Name"
pip install -r requirements.txt  # if available

# Run the tool
python tool_name.py
```

> **💡 Tip:** Most tools work as standalone scripts. No global installation required!

## 🛠️ **Tool Details**

### 1. [**PDF Searcher**](https://github.com/aminmotamedi1400/mini-tools/tree/main/pdf-searcher) 🔍

> *"Find text across thousands of PDFs in milliseconds."*

**Features:**
- 🔎 **Instant Search** – BM25-powered relevance ranking
- 📄 **Context Preview** – See surrounding text of matches
- 🚀 **SumatraPDF Integration** – Opens PDFs at exact page with highlighting
- 📊 **Export Results** – JSON/TXT format for research analysis

**Perfect for:** Students, researchers, lawyers – anyone working with document collections.

```bash
cd pdf-searcher
python ui.py
```

---

### 2. [**Chat Searcher**](https://github.com/aminmotamedi1400/mini-tools/tree/main/chat-searcher) 💬

> *"Turn your AI conversations into a searchable Obsidian knowledge base."*

**Features:**
- 📇 **Bulk Indexing** – Scans folders recursively for `.md` chat logs
- ⚡ **Fast Search** – Local inverted index for instant results
- 🏔️ **Obsidian Native** – Opens results directly in Obsidian vault
- 🔒 **Privacy First** – Everything runs locally

**Perfect for:** AI power users who save ChatGPT/Claude conversations as markdown.

```bash
cd chat-searcher
python chat_ui.py
```

---

### 3. [**Accountant**](https://github.com/aminmotamedi1400/mini-tools/tree/main/Accountant) 💰

> *"Take control of your finances."*

Track expenses, generate reports, and visualize spending patterns. Perfect for personal budget management.

---

### 4. [**Thesis Manager**](https://github.com/aminmotamedi1400/mini-tools/tree/main/Thesis%20Manager) 📝

> *"Your academic writing companion."*

Manage citations, track writing progress, organize research papers, and maintain bibliography – all in one place.

---

### 5. [**File Folders Organizer**](https://github.com/aminmotamedi1400/mini-tools/tree/main/File%20Folders%20Organizer) 📂

> *"Clean up the digital mess."**

Automatically sort files by type (images, documents, videos, archives) into organized folders. Run it on your Downloads folder weekly!

---

### 6. [**Password Manager**](https://github.com/aminmotamedi1400/mini-tools/tree/main/Password%20Manager) 🔐

> *"Security without complexity."**

Generate strong passwords, store credentials securely, and auto-fill login forms. Your vault, encrypted and local.

---

### 7. [**Shopping Management**](https://github.com/aminmotamedi1400/mini-tools/tree/main/Shopping%20Management) 🛒

> *"Never forget milk again."**

Create shopping lists, track prices across stores, manage budgets, and get total cost estimates before you shop.

---

### 8. [**RAG Tool**](https://github.com/aminmotamedi1400/mini-tools/tree/main/RAG) 🤖

> *"Chat with your documents using AI."**

Load PDFs, TXT, or markdown files and ask questions using semantic search. Perfect for document Q&A without uploading to the cloud.

---

### 9. [**Persian Markdown Viewer**](https://github.com/aminmotamedi1400/mini-tools/tree/main/Persian%20Markdown%20Viewer) 📖

> *"RTL-friendly markdown reading."**

View markdown files with proper Persian/Arabic text rendering. Supports bidirectional text and custom styling.

---

### 10. [**Language Learning Manager**](https://github.com/aminmotamedi1400/mini-tools/tree/main/Language%20Learning%20Manager) 🌍

> *"Master new languages, one word at a time."**

Track vocabulary, set daily goals, use spaced repetition flashcards, and monitor your learning progress over time.

---

### 11. [**Challenges Manager**](https://github.com/aminmotamedi1400/mini-tools/tree/main/Challenges%20Manager) 🏆

> *"Level up your coding skills."**

Organize coding challenges by difficulty and topic. Track solutions, notes, and your learning journey.

---

### 12. [**CSV Backup Tool**](https://github.com/aminmotamedi1400/mini-tools/tree/main/backup%20csv) 💾

> *"Never lose data again."**

Automated CSV backups with timestamps, compression, and rotation. Set it and forget it with cron.

---

### 13. [**PDF Concatenator**](https://github.com/aminmotamedi1400/mini-tools/tree/main/PDF%20concatinator) 📑

> *"Merge PDFs in seconds."**

Combine multiple PDFs into one, reorder pages, and compress the output. CLI and GUI versions available.

## 🤝 **Contributing**

Found a bug? Have a feature request? Want to add your own mini-tool?

1. Fork the repository
2. Create your feature branch (`git checkout -b feature/amazing-tool`)
3. Commit your changes (`git commit -m 'Add amazing tool'`)
4. Push to the branch (`git push origin feature/amazing-tool`)
5. Open a Pull Request

**Tool submission guidelines:**
- Keep it **mini** (under 500 lines when possible)
- Include a clear `README.md` in your tool's folder
- Add usage examples
- No external dependencies unless absolutely necessary
